# Repository Guidelines

## Project Structure & Module Organization

This repository is a collection of concurrency exercises and notes rather than a single application. C++ examples live under `cpp/`: reusable demonstrations are in `cpp/libs/`, numbered exercises are in `cpp/problems/`, and topic notes are in `cpp/docs/`. `PROBLEMS.md` describes the main exercises. Reading material is listed in `books/list.md`; `books/LittleBookOfSemaphores/` is a Git submodule, so avoid mixing upstream book changes into repository contributions.

## Instructions

- The aim in here is to learn and guide the user, use the tutor skill
- When we are working on problems from "LittleBookofSemaphores", refer to the actual book source code so that you do not get the task wrong or do not present a weaker solution as done.
