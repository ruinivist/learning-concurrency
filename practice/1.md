# Practice 1

## Producer Consumer ( 1 hour )

Assume **try semantics** and **bounded**.

- Write a templated SPSC using atomics.
  - Why is the `alignas` needed?
  - Are the contructor operations on the queue safe? Movable? Copyable?
  - If I swap the loads for head and tail ( the lines on which they are written ), what does that entail?
- What do you need to convert it to an MPCMC? Implement.
  - Can you justify the memory orderings used?
- Can you write the SPSC with backpressure? ( blocking )

## Thread pool ( 1 hour )

- Write a simple fire and forget thread pool
- How do we convert it to have return values and arguments? Implement
- What is work stealing? How does this pool change to make it work stealable.
